# Brief Roulette ✳

An interactive creative challenge generator for designers, storytellers and curious minds.

## Features
- Random product, audience, mood and creative twist
- Lock or respin a brief
- Concept name, hook and idea notes
- Auto-save locally in the browser
- Copy and export briefs as text files

## Run locally
Open `index.html` in any modern browser. No build tools or API keys are needed.

## Deploy to Vercel
Import `ishu1284/brief-roulette` from GitHub at https://vercel.com/new. Select **Other** as the framework preset, set root directory to `./`, leave build command empty, and click **Deploy**.

## Privacy
Drafts live in the visitor's browser local storage. No accounts or server storage.
